《Emoji连连看》是一款经典连线消除游戏。规则极简，但高分需要极强的观察力和路径规划能力。

🔗 Two matching Emojis, up to two turns, connect them to clear. Sounds casual? Try it on a 12×10 board with 30 Emojis and a 90-second timer.

Emoji Link-Up is a classic connect-and-clear puzzle. The rules are minimal, but high scores demand sharp observation and path planning.

🎮 核心规则：什么能连，什么不能 🎮 Core Rules: What Connects, What Doesn't

  • 相同Emoji：只有完全相同的两个Emoji才能连线消除。
  • 最多两拐：连线可以是直线、一个拐弯、或两个拐弯。超过两拐的连线无效。
  • 不能穿过：连线不能穿过其他Emoji方块，只能穿过空白区域。
  • 边界绕行：可以利用棋盘边缘绕行——这是高级技巧的核心。
  • Matching Emojis: Only identical pairs can be connected.
  • Max two turns: The path can be straight, one turn, or two turns. Three+ turns = invalid.
  • No passing through: The path can't cut through other Emoji tiles — only through empty space.
  • Edge wrapping: You can route along the board edges — this is the core of advanced play.

核心真相：连连看的高手和新手之间的差距，不在于"找得快"，而在于"找得对"——优先消除能"打开局面"的方块，而不是随手点两个。

Core truth: The gap between pros and beginners isn't "finding fast" — it's "finding right." Prioritize clears that "open up the board," not random pairs.

🧠 三阶搜索法：从新手到高手 🧠 Three-Stage Search Method

第一阶：相邻优先（0-30秒）

Stage 1: Adjacent First (0-30s)

  • 只看相邻：开局时不要试图找远处的配对。先快速扫描所有"相邻"（包括对角相邻）的相同Emoji，这些是零拐弯的连线，秒消。
  • L型扫描：用眼睛画"L"字扫描棋盘——先看横排，再看竖排。这样不会遗漏相邻配对。
  • 消除边界：优先消除靠近边缘的方块。边缘方块的路径选择最少，容易在后期被困住。
  • Adjacent only: At the start, don't hunt for distant pairs. Quickly scan all "adjacent" (including diagonal) matching Emojis — these are zero-turn connections, instant clears.
  • L-scan pattern: Scan the board in an "L" pattern — scan rows first, then columns. This ensures you don't miss adjacent pairs.
  • Clear edges first: Prioritize edge-adjacent tiles. Edge tiles have the fewest path options and get trapped easily in late game.

第二阶：边界绕行（30-60秒）

Stage 2: Edge Routing (30-60s)

  • 利用棋盘外缘：当两个相同Emoji被其他方块隔开时，尝试从棋盘边缘绕行。边缘被视为"空白通道"，可以绕过障碍物。
  • "开道"策略：每消除一对，就可能为另一对创造新的通道。思考"消除这对之后，哪些被堵住的配对会被解放"。
  • 不要堵角：尽量避免把方块消得只剩角落几个——角落方块的连线路径极度受限。
  • Use board perimeter: When matching Emojis are separated by other tiles, try routing along the board edges. Edges count as "empty corridors" that bypass obstacles.
  • "Path opening" strategy: Every clear can create new paths for other pairs. Think: "After clearing this pair, which blocked pairs will be freed?"
  • Don't corner yourself: Avoid clearing so aggressively that only a few corner tiles remain — corner tiles have extremely limited connection paths.

第三阶：预判残局（60秒+）

Stage 3: Endgame Prediction (60s+)

  • "死局"识别：某些配对被完全包围，没有任何路径可以连接。提前识别这些"死局"方块，在它们周围创造空间。
  • 对称消除：棋盘往往有某种对称分布。利用对称性——消除左上角的配对时，右下角的对应配对很可能也被解放了。
  • 时间管理：最后20秒不要犹豫。如果5秒内找不到配对，使用"提示"功能（如果有）。提示的扣分比超时少得多。
  • "Dead pair" detection: Some pairs are completely surrounded with zero path between them. Identify these "dead pairs" early and create space around them.
  • Symmetric clearing: Boards often have symmetric distributions. Use symmetry — when you clear a pair in the top-left, the corresponding pair in the bottom-right is likely freed too.
  • Time management: In the last 20 seconds, don't hesitate. If you can't find a pair in 5 seconds, use the "hint" function (if available). Hint penalties are far less than timeout penalties.

🎯 各难度模式策略差异 🎯 Difficulty Mode Strategies

  • 简单模式（8×6，12种Emoji）：练手阶段。重点训练"相邻优先"和"L型扫描"，不要过度依赖边界绕行。
  • 中等模式（10×8，20种Emoji）：开始需要边界绕行。每消除一对后，快速扫一眼是否创造了新的相邻配对。
  • 困难模式（12×10，30种Emoji）：考验全局规划。开局10秒不动，先在心里标记出3-4对"最容易连"的配对，按顺序执行。
  • Easy (8×6, 12 Emojis): Training phase. Focus on "adjacent first" and "L-scan." Don't over-rely on edge routing.
  • Medium (10×8, 20 Emojis): Edge routing becomes necessary. After each clear, quickly scan if new adjacent pairs were created.
  • Hard (12×10, 30 Emojis): Tests global planning. Spend the first 10 seconds without clicking — mentally mark 3-4 "easiest to connect" pairs, then execute in order.
